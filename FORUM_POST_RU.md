# ANENJI SH12100-H: мониторинг BMS через Bluetooth на Windows и наблюдения при зарядке PowMR

Подготовлен открытый проект **ANENJI BMS Monitor** — программа для просмотра параметров двух LiFePO₄ АКБ ANENJI 12,8 В 100 А·ч через BLE. Испытаны Windows, Python 3.13.17, Bleak 3.0.2 и aiobmsble 0.30.0.

**Программа показывает** напряжение, ток, SOC, 4 ячейки, разброс напряжений, температуру, состояние MOS, ошибки и ведёт CSV-историю. Опрос — только вручную по кнопке. Доступна исходная версия для сборки под Windows; у пользователя свои имена BLE задаются в `batteries.json`.

**Что удалось увидеть:**

- Использовались BLE GATT-каналы `FFFB` (запрос) и `FFFC` (ответ).
- На Windows наблюдались `Could not start notify on 0019: Unreachable` и `Characteristic fffc was not found!`; затем обе батареи успешно читались двумя вариантами программы. Причина временного отказа не установлена.
- На связке PowMR POW-HVM1K-12V + две ANENJI при уставках Bulk 14,2–14,4 В / Float 13,7 В ток заряда по BMS неоднократно уменьшался до 0 А возле 13,61 В. BMS показывали около 93% и 90%. У одной АКБ дельта напряжений ячеек к окончанию зарядки достигала ~46–50 мВ, при разряде снижалась до ~4–7 мВ. Это наблюдение, не диагноз и не доказательство того, что PowMR достигал Bulk 14,4 В.

Подробные исходники, инструкции и измерения — в открытом репозитории `anenji-bms-monitor` (ссылка после публикации).

**Важно:** это исследовательский мониторинг, а не система защиты батарей. Готовый EXE конкретного владельца и его идентификаторы BLE не публикуются.
