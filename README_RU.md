# ANENJI BMS Monitor (Windows) — открытые результаты экспериментов

**Язык:** [English](README.md) · **Материалы:** наблюдения пользователя, 6–12 ноября 2026 г.

Проект для чтения данных **двух аккумуляторов ANENJI LiFePO₄ 12,8 В / 100 А·ч**, оборудованных BLE BMS с рекламируемым именем `SH12100-H-*`. Рабочая проверка проведена на Windows с **Python 3.13.17, Bleak 3.0.2 и aiobmsble 0.30.0**. Программа показывает напряжение, ток, SOC, ячейки, температуру, флаги MOS, ошибки и записывает CSV на Рабочий стол.

> **Ограничение безопасности:** проект предназначен только для наблюдения и анализа. Данные BLE могут быть ошибочными или недоступными. Не используйте программу для защиты батареи, автоматического управления зарядом, отключения при аварии или принятия решений, от которых зависит безопасность.

## Быстрый запуск исходников

1. На Windows установите Python (рекомендуется версия 3.13) и зависимости: `py -m pip install -r requirements.txt`.
2. Создайте рядом с исходниками `batteries.json` по образцу `batteries.example.json`. Замените **оба демонстрационных имени** точными именами *Ваших* BMS; они должны совпадать с именами Bluetooth-рекламы.
3. Запустите `py battery_gui_v8_13.py`. Нажмите **«Обновить»**; сканирование и чтение выполняются только по кнопке.
4. Для EXE также установите PyInstaller: `py -m pip install -r requirements-build.txt` и запустите `BUILD_ANENJI_BMS_v8_13.bat`. Файл `batteries.json` должен лежать рядом с EXE при запуске.

Никаких персональных адресов Bluetooth, пользовательских путей Windows или журналов владельца проект не содержит. Готовый Windows EXE, собранный для конкретных аккумуляторов владельца, **не публикуется**.

## Что было подтверждено

- Обе BMS действительно передают BLE-объявления `SH12100-H-*`.
- Для испытанных устройств GATT содержит `FFFA` (сервис), `FFFB` (передача запросов) и `FFFC` (уведомления); при успешном опросе известен ответ на read-only запрос `A5 A5 00 03 ...`.
- На Windows 12.11.2026 наблюдались `Could not start notify on 0019: Unreachable` и `Characteristic fffc was not found!`; в более поздних запусках чтение обеих батарей **успешно** и в варианте `aiobmsble` 8.12, и через прямой `Bleak` 8.13.
- **Причина временных сбоев не доказана**, как и преимущество 8.13 по надёжности: при успешных тестах 8.13 дополнительный обход подписки не использовался.
- В зарядных экспериментах с PowMR при установках Bulk 14,2 / 14,3 / 14,4 В, Float 13,7 В наблюдались завершения тока около **13,61 В**, при этом SOC BMS мог быть **93%/90%**, а дельта одной батареи достигала **~46–50 мВ**. Значение 14,4 В — **уставка**, фактическое достижение его не зафиксировано. Реальная стадия Bulk/Float прибором не подтверждена.
- При разряде дельта той же батареи могла снижаться до **~4–7 мВ**; отдельная батарея имела ~5–10 мВ. Это **не диагноз** и не доказывает ни отказ балансира, ни корректность показаний SOC.
